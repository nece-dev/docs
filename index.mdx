## What you can build

- Fetch current plans and network availability.
- Purchase data for a recipient through a connected SIM.
- Read transaction history for reconciliation and reporting.
- Create and revoke API keys from the OnePanel dashboard.

<Note>
  The API resolves plan pricing from the server-side catalog. Send the current `plan_id`; never send or trust a client-calculated amount.
</Note>

## Base URL

```text
https://sffhehsa.onepanel.ng/api/v1
```

The unversioned `/api` path remains available as a legacy alias. New integrations should use `/api/v1`.
