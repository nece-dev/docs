## 1. Create an API key

Sign in to OnePanel, open **Settings → API keys**, and create a key. The raw key is shown once, so store it in a server-side secret manager.

<Warning>
  Never put an API key in browser JavaScript, mobile app source, a public repository, or a client-visible URL.
</Warning>

## 2. List supported networks

```bash
curl https://api.onepanel.ng/api/v1/networks
```

## 3. Fetch a current catalog

```bash
curl "https://api.onepanel.ng/api/v1/bundles?carrier=mtn"
```

Use the returned `id` as the `plan_id` in a purchase request. Catalog IDs and prices can change.

## 4. Purchase a plan

```bash
curl -X POST https://api.onepanel.ng/api/v1/purchase \
  -H "Authorization: Bearer $ONEPANEL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "carrier": "mtn",
    "plan_id": "1650",
    "recipient": "07068765000"
  }'
```

Every successful purchase charges the configured flat platform fee of **₦2**. The account must have sufficient wallet balance and an active connected SIM for the selected carrier.

## 5. Check transaction history

```bash
curl https://api.onepanel.ng/api/v1/transactions \
  -H "Authorization: Bearer $ONEPANEL_API_KEY"
```
